# Type crossings

A conversion is this system's permission for a value of one type to be used as another. Every one of them carries a reason, and the reason is required rather than optional precisely so that this page can exist: someone asking why an invoice's email address is allowed to become a mailbox address gets an answer written by the person who allowed it, not a shrug.

Declaring a crossing is also the only way to make one. Two newtypes over `String` do not convert because they are both strings; they convert because a line in the specification says they may.

This system declares no crossings. Every type is used only as itself.
